What is CD Burner

From folder to disc-ready WAV

CD Burner is a desktop app for arranging albums and mixtapes onto Compact Disc capacity. Choose CD74, CD80, or a custom length, drop in a folder, balance Side A and Side B, then Prepare and export WAV for your burner software.

FAQ

Common questions

Do I need a DAW or plugin host?

No. CD Burner is a standalone desktop application. Import audio, prepare it, and export WAV — all in one window.

Which audio formats can I import?

WAV, FLAC, AIFF, OGG, and MP3. Export is WAV.

MacOS blocks CD Burner after download
Why Side A and Side B on a CD?

CD Burner keeps the familiar Side A / Side B layout for program balance. Disc length (CD74 / CD80) is split evenly across both sides so you can shape the listening flow before burning.

Can I build a full disc from a folder?

Yes. Import a folder, arrange tracks in the editor, check fit for CD74 or CD80, then prepare and export Side A/B WAV files.
